# Rust dependencies - crates.nvim (lua/hwangfu/crates.lua; Cargo.toml only)

| Key | Action |
|-----|--------|
| `<leader>cv` / `<leader>cf` / `<leader>cd` | Versions / features / dependencies popup |
| `<leader>cu` / `<leader>cU` | Update / upgrade crate (visual: all selected) |
| `<leader>ct` | Toggle inline latest-version info |
| `<leader>cr` | Reload crates.io data |
| `<leader>cx` / `<leader>cX` | Expand to inline table / extract into table |
| `<leader>cD` / `<leader>cC` / `<leader>cH` / `<leader>cR` | Open docs.rs / crates.io / homepage / repository |

Completion, hover (K) and code actions (\<leader\>ca) ride the LSP
layer.
