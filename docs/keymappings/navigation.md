# Navigation keys (lua/hwangfu/keymappings/navigation.lua)

| Key | Mode | Action |
|-----|------|--------|
| `Ctrl-T` | n | Toggle the oil sidebar at buffer's directory (35-col left split since 2026-08-14) |
| `]b` / `[b` | n | Next / previous buffer |
| `<leader>bd` | n | Close buffer |

Built-ins worth remembering (not mapped here): `Ctrl-O` / `Ctrl-I`
walk the jumplist back / forward after gd-style jumps; `Ctrl-^`
toggles to the previous buffer.

Keys *inside* oil listings live in [explorer](explorer.md).
