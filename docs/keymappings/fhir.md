# FHIR

*Defined in `lua/jwa/plugins/spec/fhir.lua` (fhir.nvim); active only in FHIR resource buffers.*

| Key | Action |
|-----|--------|
| `gd` | Go to the referenced resource |
| `gr` | Find usages of this resource |
| `<leader>fo` | Outline |
| `<leader>fe` | Evaluate |
| `gl` | Diagnostics |
| `ga` | Apply a fix |
