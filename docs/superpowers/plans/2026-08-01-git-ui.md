# Git UI Implementation Plan (lazygit float + diffview.nvim)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hand-rolled lazygit floating terminal (`<leader>gg`, no plugin) and diffview.nvim (`<leader>gd/gh/gH`) per the approved spec at `docs/superpowers/specs/2026-08-01-git-ui-design.md`.

**Architecture:** New `lua/jwn/git.lua` module (native float + jobstart, wired from root init.lua like keymap); diffview.nvim as a lazy `cmd`+`keys` spec in `lua/jwn/plugins.lua` placed with the git plugins next to gitsigns; cross-references added to the gitsigns comment and keymap.lua's header index.

**Tech Stack:** Neovim >= 0.11 (`vim.fn.jobstart` with `term = true`, `vim.fs.root`), lazy.nvim, lazygit (system binary), sindrets/diffview.nvim.

## Global Constraints

- ASCII only in every config file; verify with the grep in each task.
- Indentation PER-FILE: `plugins.lua` and root `init.lua` use TABS; `git.lua` (new) and `keymap.lua` use 4 SPACES. Never run stylua.
- NOT a git repository: no commit steps; each task ends with a parse-check.
- Float size 90% x 90%, `border = "rounded"`, per approved design.
- diffview adopted with dormancy documented in its spec comment (upstream last push 2024-08).
- The git-root guard MUST prevent launching lazygit outside a repository.
- Parse-check command: `nvim --clean --headless -c "lua assert(loadfile('<FILE>'))" -c q`

```lua
-- ============================================================================
-- Git UI: lazygit in a floating terminal.
--
-- No plugin behind this - the float is ~40 lines of native API (scratch
-- buffer + nvim_open_win + jobstart with term = true), which fits how this
-- config leans elsewhere: native vim.lsp.config for LSP, built-in gc for
-- commenting, vim.snippet for snippets. lazygit itself is installed
-- system-wide (a `go install` binary on PATH).
--
-- Division of labor across the git tooling:
--   * gitsigns (plugins.lua)  - in-buffer hunks: signs, stage / reset,
--                               blame, buffer-vs-index diffs (<leader>h*).
--   * THIS MODULE             - repo-level porcelain: stage, commit,
--                               branch, push / pull, conflicts -
--                               everything lazygit does, floating over
--                               the editor.
--   * diffview (plugins.lua)  - read-only inspection: whole-changeset
--                               side-by-side diffs and history
--                               (<leader>gd / gh / gH).
--
-- Keymap (global, normal mode):
--   <leader>gg   open lazygit in a centered float (90% x 90%, rounded
--                border), rooted at the current buffer's repository.
--                Quit lazygit (q) and the float collapses.
--
-- Guard: refuses to launch outside a git repository (vim.notify error
-- instead). lazygit's out-of-repo behavior is an interactive "create a
-- new repo here?" prompt, which a stray keypress should never reach.
--
-- gitsigns needs no refresh plumbing after lazygit actions: it watches
-- the git dir and updates signs / statusline counts on its own.
-- ============================================================================

local M = {}

-- Open `cmd` (an argv table) in a centered floating terminal, running in
-- directory `cwd`. Kept generic so a second tool (tig, ...) is a
-- one-keymap addition, not a rewrite.
local function open_term_float(cmd, cwd)
    -- Scratch buffer: no file, unlisted, wiped when the float closes.
    local buf = vim.api.nvim_create_buf(false, true)

    -- 90% of the editor, centered. vim.o.lines includes the cmdline and
    -- statusline rows; the -2 keeps the border on screen.
    local width = math.floor(vim.o.columns * 0.9)
    local height = math.floor((vim.o.lines - 2) * 0.9)
    local win = vim.api.nvim_open_win(buf, true, {
        relative = "editor",
        width = width,
        height = height,
        col = math.floor((vim.o.columns - width) / 2),
        row = math.floor((vim.o.lines - 2 - height) / 2),
        style = "minimal",
        border = "rounded",
    })

    -- term = true turns the buffer into a terminal running cmd (the
    -- Neovim 0.11 replacement for the deprecated termopen()). cwd pins
    -- the program to the resolved repo root - without it, lazygit would
    -- open whatever repo Neovim's :cwd happens to be in. on_exit
    -- collapses the float when the program quits; the validity checks
    -- cover a window the user already closed manually with :q.
    vim.fn.jobstart(cmd, {
        term = true,
        cwd = cwd,
        on_exit = function()
            vim.schedule(function()
                if vim.api.nvim_win_is_valid(win) then
                    vim.api.nvim_win_close(win, true)
                end
                if vim.api.nvim_buf_is_valid(buf) then
                    vim.api.nvim_buf_delete(buf, { force = true })
                end
            end)
        end,
    })

    -- Land in terminal-insert mode so lazygit sees keystrokes right away.
    vim.cmd.startinsert()
end

-- require("jwn.git").setup()
function M.setup()
    vim.keymap.set("n", "<leader>gg", function()
        -- Git-root guard: resolve from the current buffer's path first,
        -- then from cwd (covers unnamed / scratch buffers). vim.fs.root
        -- returns nil when no .git marker exists on the way up.
        local root = vim.fs.root(0, ".git")
            or vim.fs.root(vim.fn.getcwd(), ".git")
        if not root then
            vim.notify(
                "lazygit: not inside a git repository",
                vim.log.levels.ERROR
            )
            return
        end
        open_term_float({ "lazygit" }, root)
    end, {
        silent = true,
        desc = "Git: open lazygit in a float",
    })
end

return M
```

Insert directly before the line `	-- Colorschemes (selected per-filetype by lua/jwn/colors.lua).` (TAB-indented), followed by a blank line separating it from the colorschemes comment:

```lua
	-- Whole-changeset diffs + history browsing (diffview.nvim).
	--
	-- The read-only INSPECTION layer of the git tooling. Complements
	-- rather than overlaps the other two git pieces:
	--   * gitsigns (above)      edits hunks inside the buffer (<leader>h*).
	--   * lazygit (<leader>gg,  acts on the repo: stage / commit / branch /
	--     lua/jwn/git.lua)  push, in a floating terminal.
	--   * diffview (this spec)  shows changesets and history in native
	--                           nvim windows with real syntax highlighting.
	--
	-- ADOPTION NOTE (2026-08): upstream is dormant - last push 2024-08,
	-- not archived, feature-complete, the largest install base in its
	-- niche, and no maintained equivalent exists. Adopted with eyes open:
	-- if a future Neovim version breaks it, replace or drop it rather
	-- than patch it.
	--
	-- Keymap quick reference (lazy `keys` below; global, normal mode):
	--   <leader>gd   DiffviewOpen             working tree vs HEAD
	--   <leader>gh   DiffviewFileHistory %    history of the current file
	--   <leader>gH   DiffviewFileHistory      history of the whole repo
	-- Inside a diffview tab:
	--   <Tab> / <S-Tab>         next / previous changed file
	--   g?                      diffview's own help for the current panel
	--   q (or :DiffviewClose)   leave the view
	-- More commands: :DiffviewOpen <rev> compares against any revision
	-- (e.g. :DiffviewOpen main...HEAD), :DiffviewToggleFiles toggles the
	-- file panel, :DiffviewRefresh re-reads git state.
	--
	-- Defaults kept throughout; diffview's default use_icons = true rides
	-- the nvim-web-devicons already installed for lualine / oil.
	{
		"sindrets/diffview.nvim",
		cmd = {
			"DiffviewOpen",
			"DiffviewClose",
			"DiffviewFileHistory",
			"DiffviewToggleFiles",
			"DiffviewFocusFiles",
			"DiffviewRefresh",
			"DiffviewLog",
		},
		keys = {
			{ "<leader>gd", "<cmd>DiffviewOpen<CR>", desc = "Git: diffview (working tree vs HEAD)" },
			{ "<leader>gh", "<cmd>DiffviewFileHistory %<CR>", desc = "Git: file history (current file)" },
			{ "<leader>gH", "<cmd>DiffviewFileHistory<CR>", desc = "Git: repo history" },
		},
		config = function()
			require("diffview").setup({})
		end,
	},
```
